# Capturas de proyectos

Coloca aqui las capturas de cada caso de estudio.

## Estructura recomendada

```text
web/assets/projects/
  training/
    01-rutinas.png
    02-plan.png
    03-mobile.png
```

## Tamano recomendado

- Desktop: 1440 x 1000 o similar.
- Mobile: 390 x 844 o similar.
- Formato: PNG para maxima nitidez, JPG/WebP si el archivo queda muy pesado.
- Evita capturar informacion privada de clientes, reservas reales, correos o paneles internos.
